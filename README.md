## 📌 Project Overview

Customer Support Ticket Analysis is a data analytics project that explores customer support requests to understand ticket categories, priority levels, agent performance, resolution time, and customer satisfaction.

Using Python and data visualization libraries, this project identifies patterns that can help support teams improve service quality and operational efficiency.

## 🎯 Project Objectives

- Analyze customer support tickets by category.
- Understand ticket priority distribution.
- Evaluate customer support agent performance.
- Measure average ticket resolution time.
- Analyze customer satisfaction ratings.
- Explore the relationship between resolution time and customer ratings.

## 💡 Business Insights

The analysis helps identify:

- The most frequently reported customer issues.
- Categories that may require additional support.
- Differences in ticket resolution times.
- Agents with lower average resolution times.
- Customer satisfaction patterns.
- Potential relationships between resolution time and ratings.

*Note: Insights are based on a synthetic practice dataset and should not be interpreted as actual company performance.*
